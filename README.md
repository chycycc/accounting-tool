# 记账账本

一个基于 Flask 的本地 Web 记账工具，专为过磅称重场景设计。数据保存在本地 `data.json`，单机运行，无任何外部依赖（全量离线）。

## 功能特性

### 📝 记录管理
- **单条录入**：逐条添加每日过磅数据
- **批量录入**：整月日历式录入，同一天支持**追加多档位行**（150/180/300 元/吨混录）
- **批量单价**：弹窗顶部工具条，一键「应用到全部」或「仅应用到空行」，实时显示当前档位
- **编辑记录**：每行 ✎ 按钮，修改原始数据或单价，kg 自动重算
- **批量删除**：勾选多条记录一键删除
- **智能解析**：支持多种输入格式
  - `750×5+422` → 展开为 750,750,750,750,750,422
  - `183包` → 自动换算为 kg（40包 = 1吨）
  - `670 800 670 670` → 空格分隔

### 📊 报表统计
- **月度汇总**：天数、总kg、总吨、总金额
- **年度报表**：各月汇总 + 全年合计（总额、月均、日均吨数、活跃天数、最高/最低月）
- **趋势图表**：折线图（金额趋势）+ 柱状图（金额对比）
- **按单价拆分**：环形图展示各单价金额占比，中心显示总金额，悬停显示占比
- **TOP 10 单日**：按金额排行，直接显示当日原始录入数据

### 💾 数据安全
- **自动备份**：每次保存前自动备份到 `backups/`，保留最近 20 份（微秒级时间戳，互不覆盖）
- **整库备份**：设置页一键导出 `账本数据备份.json` / 导入恢复（导入前有覆盖确认）
- 本地存储，数据不怕丢

### 📥 导出功能
- 导出月份明细 Excel
- 导出年度报表 Excel
- 自动带公式，用 Excel 打开即计算

### ⚙️ 设置管理
- 单价档位管理（增删）
- 支持多单价并存（150/180/300 元/吨等）
- 报表模块开关（图表、饼图、TOP10 可独立启停）
- 数据管理（导出/导入整库备份）

### 🎨 界面特色
- 深色/浅色主题切换
- 工业风设计（Inter + JetBrains Mono 等宽数字）
- 图表千分位显示，移动端自适应
- 图表库与字体全部本地化，无外网请求

## 快速开始

### 1. 安装依赖

```bash
pip install flask openpyxl
```

### 2. 启动服务

```bash
cd accounting-tool
python app.py
```

生产环境关闭调试模式：

```bash
FLASK_DEBUG=0 python app.py
```

### 3. 打开浏览器

访问 http://localhost:5000

## 项目结构

```
accounting-tool/
├── app.py              # Flask 后端（接口 + 页面入口）
├── data.json           # 数据存储
├── requirements.txt    # Python 依赖
├── .gitignore          # 忽略备份与缓存
├── backups/            # 自动备份目录（每次保存自动生成）
├── static/
│   ├── style.css       # 样式文件
│   ├── chart.umd.min.js  # 图表库（本地离线）
│   └── fonts/          # 本地字体（woff2）
└── templates/
    └── index.html      # 前端页面（单文件内联 JS）
```

## 数据格式

数据存储在 `data.json` 中：

```json
{
  "prices": [150, 180, 300],
  "records": {
    "2026-07": [
      {
        "id": "abc123",
        "date": "7.1",
        "raw": "670+800+670+670",
        "kg": 2810,
        "price": 150
      }
    ]
  }
}
```

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 主页 |
| GET | `/api/prices` | 获取单价列表 |
| POST | `/api/prices` | 添加单价 |
| DELETE | `/api/prices/<id>` | 删除单价 |
| GET | `/api/months` | 获取所有月份 |
| GET | `/api/records?month=2026-07` | 获取某月记录 |
| POST | `/api/records` | 添加记录 |
| PUT | `/api/records/<id>` | 编辑记录（raw/price，kg 重算） |
| DELETE | `/api/records/<id>` | 删除记录 |
| GET | `/api/report?year=2026` | 获取年度报表 |
| GET | `/api/top10?year=2026` | TOP 10 单日排行 |
| GET | `/api/export?month=2026-07` | 导出月份 Excel |
| GET | `/api/export_report?year=2026` | 导出年度 Excel |
| GET | `/api/export_data` | 导出整库 JSON 备份 |
| POST | `/api/import_data` | 导入整库 JSON 备份（覆盖） |

## 技术栈

- **后端**：Python Flask
- **前端**：HTML + CSS + JavaScript（单文件内联）
- **图表**：Chart.js（本地）
- **字体**：Inter + JetBrains Mono + Noto Serif SC（本地）
- **存储**：本地 JSON 文件

## 注意事项

- 数据保存在本地 `data.json`，请勿手动删除
- 每次保存会自动在 `backups/` 生成备份（保留最近 20 份），可从设置页恢复
- 首次运行会自动创建数据文件
- 服务运行期间可随时在浏览器操作
- 支持手机访问（自适应布局）
